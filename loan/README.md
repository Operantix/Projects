## ✨ Features in Version 1.0.1

- 📊 **Real-time Member Loan Ledger**: View Society Loans, Flood Advances, Festival Advances, Housing Advances, and Interest breakdown.
- 💼 **Share Capital & CTD Portal**: Dedicated dashboard for viewing Member Share Capital and Compulsory Thrift Deposit (CTD) balances.
- 🔴 **Smart Inactive Detection**: Automatic `INACTIVE` status indicators for members or loan categories with zero balance.
- 🔄 **Realtime Cloud Synchronization**: Seamless synchronization between the Admin Web Sheet Portal (`localhost:3000`) and the Android mobile client via Google Firebase Firestore.
- 🚀 **In-App Force Update Engine**: Built-in prompt to alert staff and members whenever new updates are released.
